📘 Komikindo API

Versi ringan. Dibuat oleh rificlynophile

Endpoints

  • /api/latest?page=1 - Komik terbaru
  • /api/komik?slug=one-piece - Detail komik
  • /api/chapter?slug=one-piece-chapter-1 - Halaman chapter
  • /api/genre?genre=action&page=1 - Berdasarkan genre
  • /api/search?s=naruto&page=1 - Cari komik
  • /api/daftar?page=1 - Semua komik
  • /api/type?type=manga&page=1 - Berdasarkan tipe (manga/manhwa/manhua)

Contoh Response

{
  "status": true,
  "data": [
    {
      "judul": "One Piece",
      "gambar": "https://...",
      "link": "https://komikindo2.com/komik/one-piece/"
    }
  ]
}
